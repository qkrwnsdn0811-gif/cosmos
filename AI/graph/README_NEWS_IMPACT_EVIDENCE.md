# 뉴스 GNN 예측력 대조 실험

2026-09-15. 사용자 요청: “한번 입증해봐.” 모델 개발 완료와 예측력 우위를 구분하기 위한
**기존 v2 모델의 과거 데이터 대조 실험**이다. 서비스 연결·모델 교체·push·MR은 수행하지 않는다.

## 결과: 전반적인 방향 예측 우위는 입증되지 않았다

추가 대조군 **6회 학습**, 총 8개 모델 비교를 완료했다. 학습·평가 624초(10분 24초).
공통 test는 **기사 8,993건 / 기사×기업 275,026쌍**이다. KOSPI 152,424쌍·556세션,
NASDAQ 122,602쌍·561세션이며 두 시장에 후보가 있는 기사는 시장별 기사 수에 중복된다.

아래는 **거래일별 동일 가중 방향 정확도**다. 기존 README의 전체 행 동일 가중 정확도와
가중치가 다르다. 예를 들어 GNN의 KOSPI 1일 전체 행 정확도는 여전히 43.16%이며,
아래 41.10%로 모델 성능이 새로 바뀐 것이 아니다.

| 모델 | KOSPI 1일 | KOSPI 3일 | NASDAQ 1일 | NASDAQ 3일 |
|---|---:|---:|---:|---:|
| 전체 다수 클래스 | 43.26% | 43.29% | 36.92% | 35.70% |
| 금융 감성 규칙 | 28.26% | 27.97% | 31.38% | 30.91% |
| LightGBM | 40.84% | 40.57% | 35.62% | 34.92% |
| **원본 GNN** | **41.10%** | **40.49%** | **35.84%** | **37.25%** |
| 시장별 통계 | 43.26% | 43.29% | 26.53% | 27.08% |
| 종목별 통계 | 40.04% | 39.82% | 35.37% | 34.62% |
| 뉴스 내용 제거 GNN | 40.55% | 40.80% | 36.08% | 37.09% |
| 기업 간 연결 제거 GNN | 41.27% | 41.52% | 35.27% | 34.62% |

**확인된 범위와 확인되지 않은 범위:**

- 방향 정확도 비교 28개 중 10개가 아래의 보정·민감도 조건을 통과했다. 감성 규칙 대비
  4개, NASDAQ 시장 통계 대비 2개, 종목 통계 대비 KOSPI 1일·NASDAQ 3일,
  LightGBM 대비 NASDAQ 3일, 연결 제거 대비 NASDAQ 3일이다.
- **전체 다수 클래스 대비 개선은 4개 시장/기간 모두 확인되지 않았다.** KOSPI는
  1일 −2.16%p, 3일 −2.80%p로 오히려 낮으며 두 lag의 보정 후에도 차이가 유의하다.
  NASDAQ 3일은 +1.56%p지만 lag 20의 보정 전 95% 구간이 **−0.87~+3.98%p**다.
- NASDAQ 3일에서는 LightGBM 대비 **+2.33%p**(Holm p: lag 5=0.00265,
  lag 20=0.00664), 연결 제거 대비 **+2.63%p**(0.0000304 / 0.000141).
  따라서 이 조건의 메시지 전달 이득은 관찰했지만 모든 시장/기간으로 확대할 수 없다.
- **뉴스 내용 제거 대비 개선은 방향·강도 오차·강도 순위의 12개 비교 모두 확인되지 않았다.**
  뉴스가 무의미함을 증명한 것은 아니며, 현재 입력 표현·학습 방식으로 내용의 추가 이득을
  보였다고 주장할 수 없다는 뜻이다. NASDAQ 3일의 그래프 이득을 뉴스 이해의 증거로 대체하지 않는다.
- 강도 MAE는 종목별 통계보다 네 조건 모두 낮았다(동일 세션 가중 오차 감소량
  KOSPI 1/3일 0.00963/0.00748, NASDAQ 1/3일 0.00633/0.00654; 강도는 0~1 척도).
  그러나 뉴스 내용 제거·연결 제거 모델보다 낮다는 근거는 없다.
- 강도 순위는 상수/감성 규칙보다 좋았지만 **종목별 통계·LightGBM·두 제거 대조군 대비
  개선은 네 조건 모두 확인되지 않았다.** 양의 순위 상관만으로 뉴스별 전파 예측 성공을 주장하지 않는다.

**현재 결론:** 실행 가능한 학습 모델은 완성됐고 일부 비교에서는 개선이 있다. 그러나
“뉴스 내용을 읽고 관계를 전파해서 단순 기준선보다 전반적으로 잘 예측한다”는 주장은
입증하지 못했다. 원본 모델을 교체하지 않는다. 다음 연구에서는 특히 내용 표현과 라벨의
시간 정합성을 개선하고, 설정을 고정한 뒤 새로운 미관측 시계열 구간을 확보해야 한다.

검증 기록: 회귀 테스트 30개 통과. 원본 모델/입력과 사전 고정 코드 해시 유지,
6개 validation 체크포인트 선택 확인. 168개 HAC·Holm 비교를 별도 계산으로 확인했고
HAC 표준오차 최대 차이는 9.97e−17이다. 기사 순위 1,600개를 개별 SciPy 계산과 대조해
최대 차이 2.22e−16. 강도 오차 평균은 원 평가의 float32 계산과 정확히 맞으며,
float64로 다시 평균할 때 최대 5.59e−9 차이가 남는다. 원본 정확도와의 차이는 0이다.
`numerical_audit.json`과 `completion.json`에 기록했다.

## 실험 전에 고정한 조건

원본 `artifacts/news_impact_v2/`의 가중치·예측·학습 입력·PCA·라벨 설정을 해시로 고정한다.
새 산출물은 `artifacts/news_impact_v2_evidence/`에만 기록한다. `protocol.json`을 추가 모델
학습 전에 저장하며, 원본 test 결과를 보기 전에 등록한 연구라고 주장하지 않는다.

- train 2017~2022 / validation 2023 / test 2024~2026-09-11. 원본과 같은 후보·라벨·행.
- 원본 GAT 3시드 앙상블을 고정한다. 결과가 유리해질 때까지 설정을 바꾸지 않는다.
- `no_content`: 임베딩과 감성을 모두 0으로 만든 뒤 **처음부터 3시드 재학습**.
  직접 언급 기업·언급 위치/횟수는 남아 있으므로 “뉴스 정보 전부 제거” 실험은 아니다.
- `no_edges`: 기업 간 엣지를 제거한 뒤 **처음부터 3시드 재학습**. GAT 자기 연결과 잔차층,
  파라미터 구조는 유지한다. 후보는 원본 그래프에서 뽑은 집합을 그대로 사용하므로
  **후보를 정한 다음 메시지 전달이 주는 이득**을 측정하며 후보 검색의 가치는 판정하지 않는다.
- 두 대조군은 기존 학습 함수·시드 0/1/2·최대 30에폭·patience 6·배치 24·손실·최적화 설정을
  그대로 사용한다. 체크포인트는 validation 손실만으로 선택한다.
- `market_prior`, `ticker_prior`: train의 시장별/종목별 클래스 비율과 강도 중앙값.
  train 이력 없는 종목은 시장 → 전체 통계로 대체한다. test 결과로 통계를 보정하지 않는다.
- 기존 전체 다수 클래스·금융 감성 규칙·LightGBM까지 **비교군 7개**를 모두 보고한다.

## 지표와 판정

주 지표는 거래일 안에서 정답률을 평균한 뒤 거래일별 동일 가중한 방향 정확도다.
기사×기업 전체 행을 동일 가중한 정확도도 별도 보고한다. 둘은 가중치가 달라 혼용하지 않는다.

보조 지표는 강도 MAE의 음수(클수록 좋음)와 기사 안에서 실제 절대 초과수익률을 얼마나 잘
정렬하는지 측정한 Spearman 순위 점수다. 같은 시장/기사에 후보 3개 이상이고 실제 값이
상수가 아닌 공통 기사만 사용한다. 예측이 상수인 모델도 제외하지 않고 0점을 부여한다.
순위 점수 역시 거래일별 평균을 내서 짝지어 비교한다. 보조 지표가 좋다는 이유로 방향
정확도 우위가 입증됐다고 바꾸어 말하지 않는다.

같은 날 여러 기사·기업과 3일 라벨 중첩을 고려해 세션별 GNN−비교군 차이에
[Bartlett 가중 Newey–West HAC](https://www.statsmodels.org/stable/generated/statsmodels.stats.sandwich_covariance.cov_hac.html)를 적용한다.
주 분석 lag 5, 민감도 분석 lag 20. lag는 기사가 관측된 거래일 간격이며 기사가 없는 거래일은
삽입하지 않는다. 정규 근사 양측 p값을 사용한다. 각 lag에서 시장 2 × 기간 2 × 지표 3 ×
비교군 7 = **84개 검정 전체에 Holm 보정**을 적용한다.
[Holm 방법 문서](https://www.statsmodels.org/stable/generated/statsmodels.stats.multitest.multipletests.html).

각 비교의 개선 판정은 **차이 > 0이고 두 lag 모두 Holm p < 0.05**다. CSV의 95% 신뢰구간은
다중 비교 보정 전 구간이며, 개선 판정에 사용하는 보정 p값과 구분한다.
“전반적인 방향 예측 우위”는 4개 시장/기간과 7개 비교군, 총 28개 비교 모두 통과할 때만
인정한다. 통과하지 않은 개별 비교도 숨기지 않는다.

## 해석의 한계

2024~2026 test는 이미 여러 차례 본 데이터다. 이번 절차는 추가 실험의 임의 튜닝을 제한하지만
기존의 탐색 이력까지 지우지 못한다. 따라서 보정 p값도 새 독립 검증의 확증으로 제시하지 않는다.
현재 생존 기업 유니버스와 현대 사전학습 언어 모델을 사용하는 역사적 평가라는 한계도 남는다.
불확실성은 학습된 앙상블을 고정한 거래일별 차이에 대한 것이며 새 학습 표본의 변동까지
추정한 것이 아니다. 미래 일반화는 별도 미관측 시계열 구간에서 확인해야 한다.

`evaluation.csv`, `comparisons.csv`, `session_differences.csv`, `verdict.json`, `completion.json`.
