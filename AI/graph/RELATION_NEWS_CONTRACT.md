# 기업 관계·기업별 뉴스 분석·근거 설명 계약

사용자가 2026-09-19 재확인한 서비스 요구사항이다. 데이터 배치가 종료되었다는 것과 아래 기능이 완성되었다는 것을 구분한다.

## 기업 간 관계: 네 종류

| 공개 코드 | 화면 표시 | 의미 | 방향 |
| --- | --- | --- | --- |
| `SUPPLY` | 공급 | 부품·제품·원자재·서비스 등을 공급하는 관계 | 공급자 → 수요자 |
| `INVEST` | 투자·지분 | 대상 기업에 대한 투자·출자·지분 보유 관계 | 투자자·보유자 → 대상 기업 |
| `PARTNER` | 협력 | 협약·제휴·공동 개발 등 기사에 명시된 협력 관계 | 대칭 |
| `COMPETE` | 경쟁 | 특정 사업·시장에서 경쟁한다고 기사에 명시된 관계 | 대칭 |

한 기업 쌍이 여러 종류의 관계를 가질 수 있다. 모든 뉴스에 네 종류의 관계가 존재해야 한다는 뜻은 아니다. 단순 공동 등장이나 같은 산업이라는 이유만으로 관계를 만들지 않는다.

기업 전체 인수는 실제 대상 법인의 인수임이 확인되는 문장에 한해 `INVEST`의 세부 유형 `company_acquisition`으로 구분한다. 지분 취득·지분 보유와 구별하며, 사업부·제품·브랜드·공장 등 자산 인수를 기업 지분 관계로 바꾸지 않는다. 과거 인수 기사만으로 현재 지분 보유·지배 관계가 유지된다고 단정하지 않는다. 내부 `ACQUIRE`를 별도의 다섯 번째 공개 관계로 내보내지 않는다.

## 뉴스가 기업에 주는 방향: 세 종류

같은 뉴스라도 기업별로 별도의 결과를 저장한다.

| 코드 | 화면 표시 |
| --- | --- |
| `POSITIVE` | 긍정 |
| `NEGATIVE` | 부정 |
| `NEUTRAL` | 중립 |

분석 전·분석 보류·실패는 감성 종류가 아닌 처리 상태다. 이때 `label=null`을 사용한다. 보류를 중립으로 채우지 않는다. 기업 A의 긍정 결과를 관계가 있는 B에 그대로 복사하거나, 경쟁 기업이므로 자동으로 부정으로 뒤집지 않는다.

현재 생성한 FinBERT 결과는 **대상 기업의 근거 문맥에 대한 금융 감성**이다. 주가 데이터를 정답으로 학습한 GNN의 영향 방향·강도 예측과는 생성 방식과 의미가 다르므로, 모델 종류와 결과 범위를 함께 전달한다.

## 관계 설명: 뉴스와 GraphRAG

관계 상세에는 관계를 뒷받침한 기사 ID, 제목, 원문 URL, 발행 시각, 원문 근거 문장과 위치가 필요하다. 문서 수는 독립된 사건 수와 다르다. 같은 기사의 제목·본문 반복이나 동일 발표를 다룬 여러 기사를 독립된 계약으로 설명하지 않는다.

GraphRAG는 선택한 기업 쌍·관계 종류에 연결된 근거를 검색하고 그 자료로 설명을 작성한다. 공급·투자는 요청 방향을 유지하고 협력·경쟁만 반대 순서의 요청을 허용한다. 기준 시점보다 뒤의 기사를 근거로 쓰지 않으며, 시간대가 없는 자료의 시간대를 임의로 만들지 않는다.

설명의 각 주장에는 원문 인용과 출처가 따라야 한다. 숫자·날짜·당사자·협약/계획 표현을 보존한다. 검증되지 않은 요약은 원문 인용으로 대체하고, 관계 근거 자체가 없으면 없다고 반환한다. 공동 언급 기사로 부족한 관계 근거를 대신하거나 LLM의 외부 지식으로 관계를 만들어내지 않는다.

설명 생성은 관계 점수나 GNN 예측값을 수정하지 않는다. 관계가 형성된 이유를 설명하는 것과, 특정 뉴스의 주가 효과가 입증되었다는 것은 별개다.

## 공시와 뉴스의 구분

뉴스와 공시는 별도 근거 출처다. 공시를 사용한다면 공시 기관·접수번호·원문 파일·인용 위치·접수 시각을 함께 보존하고, 관계 점수는 `news_score`와 `disclosure_score`로 나누어 계산한다. 근거가 없는 출처는 `NULL`이며 다른 출처의 점수를 복사하지 않는다.

기존 `lake_disclosures.py`는 DART 정기보고서의 최대주주 표를 이용한 지분 관계 추출을 구현한다. SEC는 공시–기업 관측 연결까지만 구현되어 있다. 기존 `relationship_score_components.py`에는 출처별 7D·30D·90D 점수 계산이 있지만, 이는 문서 근거량의 표시용 점수이며 주가 영향도나 확률이 아니다.

이번 새 지식그래프와 관계 설명은 **뉴스 자료만 사용한다**. 공시 수집·추출 기반 코드가 있다는 이유로 이번 GraphRAG가 공시까지 검색하거나 `disclosure_score`를 갱신했다고 말하지 않는다. 새 뉴스 결과와 실제 공시 근거의 병합·점수 재집계·서비스 적재는 별도 작업이다.

## 현재 산출물과 후속 연결

`kg_grounded_full_20260918_v1`은 뉴스 정제·연결·감성 및 초기 관계 근거의 로컬 배치 결과다. 원본과 기존 결과를 보존한 채 네 종류 관계 추출과 관계별 GraphRAG 연결을 별도 버전으로 보완한다. 완료된 뉴스 정제와 감성을 다시 계산할 필요는 없다.

기존 `news_graphrag.py`는 예전 GNN 번들의 뉴스 영향 설명에 사용된다. 새 관계 데이터의 GraphRAG는 관계 조회용 어댑터를 통해 연결하며, 기존 생성·인용·함의 검증 구성 요소를 재사용한다. 로컬 검증 완료와 백엔드/API/화면 반영은 별도 작업이며, 이번 수정으로 운영 DB나 HDFS를 갱신하지 않는다.
