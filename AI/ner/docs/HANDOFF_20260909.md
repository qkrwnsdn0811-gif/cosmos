## 3. 처음 보는 사람이 10분 안에 돌려보기

로컬 PC(Windows)에서. Python 3.12와 `uv`가 있으면 됩니다.

```bash
cd AI/ner
uv venv .venv --python 3.12
uv pip install --python .venv/Scripts/python.exe pandas pyarrow pyahocorasick
PYTHONUTF8=1 .venv/Scripts/python.exe build_aliases.py            # seeds → data/aliases.csv 재생성
PYTHONUTF8=1 .venv/Scripts/python.exe -m unittest tests.test_matcher
```

```python
from matcher import CompanyMatcher
m = CompanyMatcher.from_csv("data/aliases.csv")
r = m.match("삼성전자, HBM 투자 확대", "삼성전자는 이날 SK하이닉스와 함께…")
r.by_ticker()   # 종목별 집계
r.mentions      # 언급 하나하나 (문자 위치 포함)
r.unresolved    # "삼성"처럼 어느 회사인지 못 정한 그룹명
```

`PYTHONUTF8=1`은 Windows 콘솔에서 한글이 깨지지 않게 하는 설정입니다.

| ⑦ | 외래어 `-즈`/`-스` 파생(시스코시스템스) | CSCO·WBD | 미탐 복구 |
| ⑧ | 국토부 실거래가 봇기사 게이트 | 000150 | 11,142 → **7,314** (-34%) |

**제거가 정당한지 표본 감사함 (부당한 제거 0건).** 가장 큰 발견은 ①이다 — APR 제거 18,097건 중 **17,697건(97.8%)이 `[뉴스핌 베스트 기사]` 사이드바 오염**이었다. 게임·예능·PMI 기사 본문 끝에 `[단독] "에이피알, 짝퉁에 당했다"`가 통째로 붙어 있어 무관한 기사 1만7천 건이 에이피알 뉴스로 집계되고 있었다. 같은 원인으로 문서당 멘션이 10~19회로 몰려 있었다. 아마존 제거 23,280건은 전부 지명(룰라-마두로 정상회담, 콜롬비아 정글 추락사고, 아마존 원주민 미생물), 두산 제거 3,830건은 전부 `'두산'(서울특별시 성동구) 전용 79.08㎡` 형태의 봇기사였다.

**주의 — ③의 APR·삼바·스트래티지는 회귀셋 노출이 0이었다.** 규칙은 좌측 문맥 앵커로 보수적으로 짰고 배치 후 표본에서 APR은 전부 연이율·협회 약어로 확인했으나, 삼바(207940)·스트래티지(MSTR)는 변화가 각각 -1.0%/-1.3%로 작아 검증 표본이 부족하다. 추가 감사 대상.

**`method=ellipsis` 멘션(26,553개)은 NER 학습셋에 그대로 넣으면 안 된다.** 스팬은 원문 토큰(`KB국민`)이고 alias는 가상 토큰(`KB국민은행`)이라 라벨이 어긋난다. NER v3를 학습할 때 `spark/make_bio_dataset.py`의 문장 제외 조건을 "unresolved 스팬 ∪ confidence<1.0 멘션 스팬"으로 넓혀야 한다.

**v1.2·v1.1 폴더는 비교용으로만 남긴다.** 공동언급 엣지는 v1.3으로 재생성해야 한다(현재 `AI/graph/data/edges_co_mention.csv`는 v1.2 기준).

- 그룹명 단독 언급(삼성, 현대, 한화)은 샘플 5,000건에서 각 120~170건으로 매우 많습니다. 사전으로는 못 정하고, NER + 링킹(Step 7) 또는 지식그래프 쪽 규칙이 필요합니다.
- 해외 뉴스는 Simply Wall St, Motley Fool 같은 미국 증시 기사라 영문 정식명으로 잘 잡힙니다(문서의 37%).

## 8. 알고 있어야 할 한계

- **성능 수치가 아직 없습니다.** "22% 문서에서 기업 검출"은 검출률일 뿐 정확도(Precision)·재현율(Recall)이 아닙니다. Step 8 수동 라벨 200건이 있어야 나옵니다.
- **record_id ≠ document_id.** 중복 통합 후 최종 ID 정책이 정해지면 mentions를 다시 매핑해야 합니다.
- **자회사 귀속은 임의 결정입니다.** 국민은행→KB금융, 신한은행→신한지주처럼 은행 자회사는 지주사로 붙였고, SK온·카카오모빌리티 같은 비상장 자회사는 버렸습니다. 팀 합의가 필요합니다.
- **GOOG/GOOGL**은 알파벳/구글 별칭을 GOOGL 하나로 보냅니다.
- **NER 학습 라벨은 사전 매칭 결과입니다(원거리 지도).** 사전에 없는 기업(현대제철, LG디스플레이)이 "기업 아님"으로 학습될 수 있습니다.
- 서버 계정이 `ubuntu` 하나라 sandbox 폴더는 권한이 아니라 이름으로 구분하는 약속입니다.

## 8-4. Step 7 완성 모듈 (2026-09-10)

