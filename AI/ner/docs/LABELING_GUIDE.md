# 기업 언급 정답 라벨링 기준 (평가셋 200건)

대상 파일: `AI/ner/data/eval/eval_set_200.jsonl` (국내 150건, 해외 50건). 한 줄이 기사 한 건입니다.
할 일: 기사를 읽고 **이 기사가 실제로 언급한 우리 대상 상장사**를 `gold` 배열에 적습니다. 예상 소요 시간은 100건에 2~3시간입니다.

```json
{"eval_id": "E001", "title": "...", "body": "...", "gold": [], "annotator": "", "note": ""}
→ {"eval_id": "E001", ..., "gold": [{"ticker": "005930", "alias": "삼성전자"}, {"ticker": "000660", "alias": "SK하이닉스"}], "annotator": "홍길동", "note": ""}
```

`ticker`는 `AI/ner/data/companies.csv`의 종목코드(KOSPI 6자리, NASDAQ 영문 티커)를 그대로 씁니다. `alias`는 기사에 실제로 쓰인 표기를 적습니다. 같은 회사가 여러 번 나와도 **한 번만** 적습니다.

## 라벨하는 것

| 상황 | 라벨 | 예 |
| --- | --- | --- |
| 정식명 | O | "삼성전자가 발표했다" → 005930 |
| 은어·약칭·영문·옛 이름 | O | 삼전, 하닉, Samsung Electronics, 대우조선해양(→한화오션) |
| 괄호 티커만 있어도 회사가 특정되면 | O | "엔비디아(NVDA)" → NVDA |
| 은행·증권 자회사 | O, **지주사로** | 국민은행 → KB금융(105560), 신한은행 → 신한지주, 한국투자증권 → 한국금융지주 |
| 제품·서비스명이 회사 이야기 맥락일 때 | O, 회사로 | "메타는 인스타그램에 새 기능을…" → META. 단, 아래 예외 참고 |
| 대상 목록에 없는 회사 | **적지 않음** | 현대제철, LG디스플레이, 카카오게임즈, 삼성디스플레이는 대상 200개에 없음 |

## 라벨하지 않는 것

| 상황 | 이유 | 예 |
| --- | --- | --- |
| 그룹명 단독 | 어느 회사인지 특정 불가 | "삼성이 발표", "현대차그룹 계열", "LG 측은" → 적지 않음. 단 "LG가 신사업" 처럼 **지주사 ㈜LG 자체**를 말하는 게 분명하면 003550 |
| 제품이 플랫폼·도구로 쓰인 경우 | 회사 언급이 아님 | "의원이 페이스북에 글을 올렸다", "아이폰으로 촬영했다", "유튜브 영상" → 적지 않음 |
| 스포츠팀·구단 | 회사가 아님 | 삼성 라이온즈, 한화 이글스, LG 트윈스, KT 위즈, 기아 타이거즈 |
| 비상장·목록 외 계열사 | 지주사로 올려 적지 않음 | SK온, GS칼텍스, 카카오모빌리티, 네이버웹툰, 삼성디스플레이 |
| 우선주 | 보통주와 별개 | 삼성전자우, 현대차2우B |
| 인명·지명·일반 단어 | | 하이브리드, 현대적인, 조선시대, 기아(배고픔) |
| 광고·기사 하단 추천 링크에 나온 회사 | 본문이 아님 | "[관련기사] 삼성전자…" 같은 꼬리표는 무시 |

## 애매할 때

- **판단이 어려우면 라벨하고 `note`에 이유를 적어 주세요.** 나중에 규칙을 정하는 근거가 됩니다. 예: `note: "삼성 단독인데 문맥상 삼성전자가 확실"`.
- 기사가 깨져 있거나 본문이 광고·목록만 있으면 `note`에 `skip`이라고 적고 넘어갑니다.
- 해외 기사에서 "Google"은 GOOGL, "Alphabet"도 GOOGL로 적습니다. GOOG는 쓰지 않습니다.
- "Strategy"(구 MicroStrategy)는 회사가 분명할 때만 MSTR. "Chief Strategy Officer"는 아님.

## 하지 말아야 할 것

- **매처 결과를 보고 베끼지 마세요.** 이 라벨은 매처를 채점하는 정답지라서 매처와 독립적으로 만들어야 합니다.
- 기사 본문을 고치거나 줄이지 마세요. `gold`, `annotator`, `note`만 채웁니다.
