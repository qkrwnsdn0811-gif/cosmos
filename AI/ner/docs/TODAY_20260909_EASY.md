## 우리가 만들고 있는 것

우리 서비스는 **"이 뉴스가 어느 회사에 좋고 나쁜 소식인지"** 를 보여주는 겁니다.
그러려면 제일 먼저 **뉴스 안에 어떤 회사가 나오는지** 찾아야 합니다. 오늘 한 일은 바로 이 "회사 찾기"입니다.

```
뉴스:  "삼성전자가 HBM 투자를 늘린다. SK하이닉스도 증설에 나선다."
결과:  삼성전자(005930) 1번, SK하이닉스(000660) 1번
```

사람이 읽으면 3초면 되는데, 뉴스가 **1,325만 건**이라 컴퓨터가 대신 읽게 만드는 겁니다.

## 오늘 한 일 4가지

### 1. 회사 이름 사전을 만들었다

컴퓨터는 "삼성전자"와 "삼전"이 같은 회사인 걸 모릅니다. 그래서 **회사 하나당 불리는 이름을 전부 적은 사전**을 만들었습니다.

| 회사 | 사전에 넣은 이름들 |
| --- | --- |
| 삼성전자 | 삼성전자, 삼전, Samsung Electronics, 005930 |
| SK하이닉스 | SK하이닉스, 하닉, 하이닉스, SK hynix |
| 엔비디아 | 엔비디아, Nvidia, NVIDIA, NVDA |
| 한화오션 | 한화오션, 대우조선해양(옛 이름), Hanwha Ocean |

- 대상 회사: 한국 100개 + 미국 100개 = **202개**
- 사전에 들어간 이름: **1,626줄** (회사 별칭 1,078 + 산업 표현 343 + 차단 목록 205, 2026-09-10 기준)
- 미국 회사 100개는 한글 이름(애플, 마이크로소프트…)이 아예 없어서 전부 손으로 넣었습니다

### 2. 뉴스에서 회사를 찾아내는 프로그램을 만들었다

사전을 들고 뉴스를 훑으면서 이름이 나오면 표시하는 프로그램입니다. 단순히 글자만 찾으면 엉뚱한 게 잡혀서 **거르는 규칙**을 넣었습니다.

| 이런 함정 | 어떻게 걸렀나 |
| --- | --- |
| "**하이브**리드 자동차" → 하이브(방탄소년단 회사)로 잡힘 | 뒤에 다른 글자가 붙으면 회사 아님 |
| "**KT**X 열차" → KT로 잡힘 | 영어 글자에 붙어 있으면 회사 아님 |
| "삼성 라이온즈가 한화 이글스를 이겼다" → 삼성·한화 회사로 잡힘 | 야구팀 이름은 통째로 제외 |
| "SK온이 공장을 짓는다" → SK(지주사)로 잡힘 | 비상장 자회사 이름은 통째로 제외 |
| "삼성전자우 급등" → 삼성전자로 잡힘 | 우선주 이름은 통째로 제외 |
| "의원이 **페이스북**에 글을 올렸다" → 메타(페이스북 회사)로 잡힘 | 제품 이름은 회사 이름이 같이 나올 때만 인정 |

마지막 페이스북 함정은 오늘 실제로 걸렸던 겁니다. 처음 돌렸을 때 **1등이 메타(18만 건)** 였는데, 알고 보니 정치인이 페이스북에 글 쓴 기사가 17만 건이었습니다. 지금은 고쳐 놨습니다.

### 3. 뉴스 1,325만 건 전체에 한 번 돌렸다

하둡 서버에 있는 뉴스 전체에 위 프로그램을 적용했습니다.

| | 한국 뉴스 | 미국 뉴스 |
| --- | --- | --- |
| 읽은 기사 | 777만 건 | 210만 건 |
| 회사가 나온 기사 | 138만 건 (18%) | 44만 건 (21%) |
| 걸린 시간 | 83분 | 19분 |

"18%밖에?"라고 느껴질 수 있는데, 나머지 82%는 정치·스포츠·연예 기사라 회사가 없는 게 정상입니다.

결과는 **하둡 안의 제 개인 폴더**에 저장했습니다. 원본 뉴스는 한 글자도 안 건드렸고, 팀 공용 폴더에도 아직 안 넣었습니다. 팀이 확인한 뒤에 옮길 예정입니다.

### 4. AI 모델 학습 준비를 끝냈다

사전은 "사전에 있는 이름"만 찾습니다. "삼성電子"처럼 처음 보는 표기는 못 잡습니다.
그래서 **문맥을 보고 회사 이름을 알아채는 AI 모델**을 추가로 만듭니다.

- 학습 데이터는 사람이 안 만듭니다. 3번에서 사전이 찾은 결과를 "정답"으로 재활용합니다 (비용 0원)
- 학습 프로그램을 다 만들었고, 제 노트북 그래픽카드로 작은 실험(1만 문장, 3분)까지 돌려 봤습니다
- 실험 모델이 "**포스코**가 손잡았다"에서 포스코를 회사로 찍어냈습니다. 사전은 "포스코"만 있으면 어느 회사인지 못 정하는데, AI는 회사인 건 알아보는 겁니다
- 본격 학습은 내일 합니다 (약 40분)

## 오늘 새로 정한 것: 회사 이름이 없는 뉴스는?

"반도체 수출 30% 증가"처럼 **회사 이름이 하나도 없는 뉴스**는 지금 방식으로는 아무 회사에도 연결이 안 됩니다.

그래서 **산업 노드를 추가**하기로 했습니다. 뉴스가 "반도체"를 말하면 → 반도체 산업 → 삼성전자·SK하이닉스·한미반도체로 이어지게 하는 겁니다. 우주 화면에서는 산업이 "은하", 회사가 "행성"이 되는 그림입니다.

오늘 **산업 18개**와 **202개 회사 배정 초안**을 만들었습니다. 팀이 한 번 봐 주셔야 합니다.

## (오후 추가) 그래서 오늘 더 한 것

- **고친 버전으로 전체 뉴스 다시 돌렸습니다.** 이제 1등이 삼성전자(179k)이고 메타는 순위 밖입니다.
- **AI 모델 본 학습을 끝냈습니다.** 17만 문장으로 50분 학습. 결과는 솔직히 "사전을 거의 그대로 따라가는 모델"입니다. 삼전은 잡지만 포스코·현대제철처럼 사전에 없는 회사는 못 잡습니다. 사전이 찾은 걸 정답으로 배웠으니 사전 밖은 회사가 아니라고 배운 셈이라, 내일 공개 기업명 데이터를 섞어 다시 학습합니다.
- **회사 관계 그래프의 재료 세 종류를 만들었습니다.** 같은 산업(1,340개), 지분 관계(38개, 예: LG화학이 LG에너지솔루션 79% 보유), 뉴스에서 같이 언급(7,507쌍, 예: 삼성SDI–LG에너지솔루션, S-Oil–SK이노베이션).
- **데이터에서 함정 하나 더 발견.** 일부 언론사 기사 본문 끝에 사이드바("오늘의 상승종목", "베스트 기사")가 통째로 붙어 있어서 HD현대와 스페이스X가 2만 번 "같이 언급"된 것처럼 나왔습니다. 관계 계산에서 600자 이내 근접 언급만 세도록 바꿔 해결했고, 본문 정제 담당과 얘기해야 합니다.

## (09-10 추가) 회사 찾기 모듈, 1차 완성

- **정답지 200건이 생겼습니다.** 제 코드를 전혀 모르는 별도 AI 에이전트 5개가 기사를 읽고 "이 기사에 나온 회사"를 적었습니다. 사람 대신이라 완벽하진 않고, 팀원이 30~50건만 확인해 주면 "사람이 검수한 정답지"가 됩니다.
- **채점 결과: 100번 찍으면 92번 맞고, 실제 나온 회사 100개 중 98개를 찾습니다.** (F1 0.94). 처음 채점 때는 0.83이었는데, 틀린 것들을 보고 사전과 규칙을 고쳐 한 바퀴 돌리니 0.94가 됐습니다. 이 "틀린 걸 보고 사전을 고치는 루프"가 설계에 있던 마지막 단계(Step 9)입니다.
- **틀렸던 이유 대부분은 기사 본문에 섞인 광고·추천기사였습니다.** 기사 끝 "이 종목도 보세요 Nvidia…", 블로그 해시태그 뒤 관련기사 목록, 본문 중간의 "→ 인텔 급등!" 같은 줄. 이런 부분을 매칭 전에 잘라내게 고쳤습니다.
- **AI 모델(NER) v2**도 붙었습니다. 사전에 없는 회사(티웨이항공, GM, 노보 노디스크…)를 찾아내서 "사전에 추가할 후보" 목록을 만들어 줍니다.
- 이제 뉴스를 넣으면 종목코드가 나오는 전 과정이 한 줄로 이어집니다. 남은 것은 다듬기와, 결과를 팀 공용 저장소로 옮기는 합의입니다.

## (09-10 저녁 추가) 전체 점검하고 고친 것

다 만들고 나서 "정말 맞게 돌아가나"를 처음부터 끝까지 훑었습니다. **네 군데가 틀려 있었습니다.**

1. **엉뚱한 회사가 끼어들고 있었습니다.** 사전 파일에 쉼표 하나가 잘못 들어가서 영어 단어 `Strategy`가 회사 이름으로 등록돼 있었습니다. 그래서 "전사전략(Corp. Strategy)센터장" 같은 문장이 미국 회사 MicroStrategy 뉴스로 잡혔습니다. 샘플 7,000건에서 103번. 전체로 치면 십만 건 규모입니다.
2. **"한화 약 3조원"이 한화 뉴스가 되고 있었습니다.** 여기서 한화는 회사가 아니라 "한국 돈으로 환산하면"이라는 뜻입니다(韓貨). 도쿄 초밥집·영국 커피 과태료 기사가 한화 관련 뉴스로 들어와 있었습니다. 한화가 나온 문서의 **절반이 이 오류**였습니다.
3. **야구장 이름 때문에 회사가 통째로 사라지고 있었습니다.** "수원 KT 위즈파크점"이라는 매장 이름 하나 때문에 그 기사 전체가 스포츠 기사로 취급돼, 제목에 KT가 있고 본문에 7번 나오는 KT 신제품 기사에서 KT가 0개로 나왔습니다.
4. **AI가 찾은 이름을 비슷한 회사에 잘못 붙이고 있었습니다.** `Pharmaceutical`(그냥 "제약"이라는 영어 단어)을 한미약품으로, `Opendoor Technologies`를 Roper Technologies로 연결했습니다. 이렇게 연결된 13건 중 **10건이 오답**이었습니다.

넷 다 고쳤고, **다시 생기지 않도록 테스트 8개를 박아 놨습니다** (테스트 33개 → 41개, 전부 통과).

그리고 고친 사전으로 **전체 뉴스를 다시 돌리는 중입니다** (09-10 밤, 약 2시간). 이번 결과부터는 배구·야구 기사가 회사 관계로 잡히던 문제도 같이 사라집니다. 지금 그래프에 있는 "삼성화재–대한항공 1,624건" 같은 관계는 전부 배구 기사였습니다.

## 아직 안 된 것 (솔직하게)

- **정확도 숫자를 아직 믿으면 안 됩니다.** 채점 결과는 F1 0.94지만, 이 200건은 제가 틀린 걸 보고 사전을 고칠 때 쓴 바로 그 200건입니다. 시험 문제를 보고 공부한 뒤 그 문제로 시험 본 셈이라 실제보다 좋게 나옵니다. 한 번도 안 본 200건을 따로 만들어 딱 한 번만 채점해야 진짜 점수가 나옵니다.
- **정답지를 사람이 확인한 적이 없습니다.** 지금 정답지는 제 코드를 모르는 별도 AI 에이전트 5개가 만든 것입니다. 팀원이 30~50건만 봐 주면 "사람이 검수한 정답지"가 됩니다.
- **결과가 아직 제 개인 폴더(sandbox)에 있습니다.** 팀 공용 폴더로 옮기려면 뉴스 1건에 붙일 ID를 무엇으로 할지 합의가 필요합니다.
- 국민은행→KB금융처럼 자회사를 어디로 붙일지는 제가 임의로 정했습니다. 팀 합의가 필요합니다.
- 기사 본문에 사이드바("오늘의 상승종목", "베스트 기사")가 섞여 들어오는 문제는 제 쪽에서 잘라내는 것으로 막았지만, **근본 원인은 본문 정제 단계**입니다. 담당자와 얘기해야 합니다.
