# NEXUS 시연 시나리오 (11/3 PT)

시험 기간(2026-07-01 ~ 10-23) 반도체 뉴스 3건으로 '뉴스 → 관계 지도 → 영향 종목 → 과거 사례·예상 변동폭 → 실제 반응' 흐름을
보여 주고, 마지막에 예상 변동폭 검증으로 마무리한다.

NEXUS가 확실하게 말하는 것은 두 가지다. **이 뉴스가 어떤 경로로 어떤 종목에 닿는지**, 그리고 **그 종목이 얼마나 크게 움직일지**(예상 변동폭,
시험 기간 검증 통과). 오를지 내릴지는 '과거 상승·하락 우세'로만 보여 준다. 화면에는 방향 적중률을 따로 띄우지 않고, 질문이 나오면 7절로 답한다.

- 숫자는 로컬 DB(`cosmos-postgres`, 2026-10-26 새벽 데이터 최신화 뒤 결과, 이벤트 115,183건, 주가는 10-23 종가)에서 뽑았다. `nexus cases`를 다시 돌리면 이 문서의 숫자를 다시 확인한다.
- 이벤트 ID는 빅카인즈 뉴스 ID로 만든 고정값(uuid5)이라 다시 적재해도 같다.
- 세 뉴스 모두 기사에 나온 기업과 공급망 추정 기업이 함께 있고, 20거래일 초과수익률이 있고, 유형이 '기타'가 아니다.
- 카드 윗줄 기업 지표(규모·시총·PER·PBR·배당)는 `nexus fundamentals`를 돌린 날 기준이라 이 문서에는 적지 않는다.

## 0. 시연 전 준비

- `docker start cosmos-postgres`, 백엔드는 `SERVER_PORT=18081`(+ 임시 `JWT_SECRET`), 프런트는 `.claude/launch.json`의 `cosmos-web`(http://localhost:5173).
- 투자 기간 토글은 브라우저에 기억된다. 시작 전에 **단기**로 맞춰 둔다.
- 화면은 아래 주소로 바로 연다. 첫 화면 기본 선택은 피드 맨 위 뉴스라, 주말 뉴스면 아직 거래일이 없어 차트 대신 "아직 이 뉴스 뒤 거래일이 오지 않아…" 문구가 나온다(정상).
- 유형 필터를 바꾸면 고른 뉴스가 풀리고 그 유형의 최신 뉴스가 열리므로, 필터는 15개 유형을 보여 주는 데만 쓴다. 예전 3D 지도 주소(`/events?event=…`)도 첫 화면으로 넘어간다.
- (선택) 관심 종목 알림(F14)을 보이려면 로그인하고 관심 기업에 SK하이닉스를 넣어 둔다. 피드 위에 최근 영향 뉴스 알림이 뜬다.
- 리허설 기록(2026-10-26, 로컬): 뉴스 ①②③의 카드 숫자·'왜 이 종목?'·3D 지도·예상 변동폭 검증 띠(±6.9% · ±3.8%)가 이 문서와 같았고, 관계 은하·뉴스·기업·커뮤니티 화면이 오류 없이 열렸다. 배포 사이트에서도 같은 순서로 한 번 더 확인한다.

## 1. 첫 화면 '이벤트' (30초)

주소: `/` (메뉴 '관계 은하 · 이벤트 · 뉴스 · 기업 · 커뮤니티' 중 '이벤트')

- 첫 화면은 뉴스 피드다(F10). 날짜는 최신순이고, 같은 날 안에서는 기업을 돌아가며 보여 준다(기업마다 그날 가장 최근 기사 → 두 번째 기사 …). 반도체 기사 열에 아홉은 SK하이닉스·삼성전자가 주인공이라, 그냥 최신순이면 두 회사만 보이기 때문이다.
- 왼쪽 뉴스마다 유형(F2)과 "하락 N · 상승 N" 요약이 붙는다(판단 보류 수는 쓰지 않는다).
- 뉴스를 고르면 오른쪽에 기사 요약, **3D 관계 지도**(가운데 별 = 기사, 안쪽 궤도 = 기사에 나온 기업, 바깥 궤도 = 공급망 추정 기업, 행성 = 원형 로고 F1), 그 아래 영향 종목 카드가 나온다.
- 맨 위 '예상 변동폭 검증' 띠는 지금은 가리키기만 하고, 끝에서 설명한다.
- 맨 아래 문구(F12): "과거 사례 통계이며 투자 권유가 아닙니다." 출처: 빅카인즈(한국언론진흥재단), FinanceDataReader, 토스증권 종목 이미지(시연용).

## 8. 숫자 다시 뽑기

```sql
-- 이벤트 한 건의 기업별 위치·방향 표시·과거 사례·실제 초과수익률·예상 변동폭
SELECT c.name, i.basis, i.hop, s.horizon, s.position, s.label, s.hold_reason, s.case_scope, s.case_count,
       round(s.down_share * s.case_count) AS down_count, s.mean_ar, a.abnormal_return, m.expected_move, m.grade
FROM event_company_impact i
JOIN company c USING (company_id)
JOIN event_company_signal s ON s.event_id = i.event_id AND s.company_id = i.company_id
LEFT JOIN event_abnormal_return a ON a.event_id = i.event_id AND a.company_id = i.company_id
     AND a.window_days = CASE s.horizon WHEN 'SHORT' THEN 3 ELSE 20 END
LEFT JOIN company_expected_move m ON m.company_id = i.company_id AND m.horizon = s.horizon
     AND m.value_chain = 'SEMICONDUCTOR'
WHERE i.event_id = 'b8b8e847-3d08-5f69-a04a-9fde01ca1edd' AND i.status = 'OK'
ORDER BY i.basis DESC, i.propagation_score DESC, c.name, s.horizon DESC;

-- 변동폭 검증과 (질문 대비) 방향 기준선 비교
SELECT horizon, grade, case_count, predicted_move, realized_move FROM move_backtest ORDER BY horizon DESC, grade;
SELECT horizon, labeled_count, hit_count, up_labels, down_labels, base_down_share, test_start, test_end
FROM signal_backtest WHERE news_type IS NULL;
```
