## 3. 알려진 문제

### 3.1 추정 전이가 지나치게 넓다 (데모 전에 조정 필요)

- 이벤트당 평균 14.5개 기업이 추정 OK로 나온다. 54%의 이벤트(69,794건)는 15개 이상이다.
- Arm, 인텔, 한미반도체, 어플라이드머티어리얼즈, ASML, 퀄컴, 브로드컴, 삼성전기는 **전체 이벤트의 90% 이상에서** 추정 OK다.
- 원인: 삼성전자·SK하이닉스가 대부분의 기사에 언급되는데, COSMOS 관계 간선(협력·경쟁)은 모두 강도 1.0이다. 1단계 협력·경쟁 간선만으로 0.5점이 나와 OK 기준 0.30을 넘는다. 사건 내용과 상관없이 같은 이웃이 매번 추정된다.
- 조정 후보:
  1. 전파 seed를 제목·본문에 나온 기업(salience 0.8 이상)으로 제한한다. 개체명 목록에만 있는 기업은 seed에서 뺀다.
  2. COSMOS 협력·경쟁 간선의 강도를 근거 수에 비례하게 낮추거나, 협력·경쟁 간선 가중치를 낮춘다.
  3. 이벤트당 추정 상한을 20개에서 8개 안팎으로 줄인다.
  4. 2단계 영향 모델(과거 초과수익률 학습)로 사건별 신호를 넣는다. 지금 점수는 그래프 구조만 반영한다.

### 3.2 근거 관계 수율이 낮다

- 기업쌍 300개 × 최근 기사 20건의 hilight에서 COSMOS 규칙이 잡은 근거는 37개, 간선으로 확정된 것은 23개다.
- COSMOS 규칙은 전체 본문 문장용으로 만들어져 짧은 hilight 조각에서는 대부분 걸러진다. 2단계 KPF-BERT 관계 판별기로 바꾸는 근거가 된다.

### 3.3 기업쌍 hilight가 캐시되지 않았다 (수정함)

- 검색 종료일이 내일로 잡혀 캐시 규칙(종료일이 오늘 이하)에 걸리지 않았다. 재실행하면 300회를 다시 호출했을 것이다.
- `analyze`의 근거 검색 종료일을 오늘로 바꿨다. 다음 실행부터 캐시된다.

### 3.4 그래프가 전체 기간 정보로 만들어진다 (평가 시 주의)

- 동시언급 NPMI, 최근 20건 근거, COSMOS 관계(2026-09 기준)를 모두 전체 기간에서 만들어 2025년 이벤트에도 적용한다.
- 데모에는 문제없지만, 2단계 시계열 검증이나 발표의 적중률 수치에 그대로 쓰면 미래 정보가 섞인다. 평가용으로는 시점별 그래프를 따로 만들어야 한다.
