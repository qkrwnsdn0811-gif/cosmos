## 3. 알려진 문제

### 3.1 추정 전이가 지나치게 넓다 (데모 전에 조정 필요)

- 이벤트당 평균 14.5개 기업이 추정 OK로 나온다. 54%의 이벤트(69,794건)는 15개 이상이다.
- Arm, 인텔, 한미반도체, 어플라이드머티어리얼즈, ASML, 퀄컴, 브로드컴, 삼성전기는 **전체 이벤트의 90% 이상에서** 추정 OK다.
- 원인: 삼성전자·SK하이닉스가 대부분의 기사에 언급되는데, COSMOS 관계 간선(협력·경쟁)은 모두 강도 1.0이다. 1단계 협력·경쟁 간선만으로 0.5점이 나와 OK 기준 0.30을 넘는다. 사건 내용과 상관없이 같은 이웃이 매번 추정된다.
- 조정 후보:
  1. 전파 seed를 제목·본문에 나온 기업(salience 0.8 이상)으로 제한한다. 개체명 목록에만 있는 기업은 seed에서 뺀다.
  2. COSMOS 협력·경쟁 간선의 강도를 근거 수에 비례하게 낮추거나, 협력·경쟁 간선 가중치를 낮춘다.
  3. 이벤트당 추정 상한을 20개에서 8개 안팎으로 줄인다.
  4. 2단계 영향 모델(과거 초과수익률 학습)로 사건별 신호를 넣는다. 지금 점수는 그래프 구조만 반영한다.

### 3.2 근거 관계 수율이 낮다

- 기업쌍 300개 × 최근 기사 20건의 hilight에서 COSMOS 규칙이 잡은 근거는 37개, 간선으로 확정된 것은 23개다.
- COSMOS 규칙은 전체 본문 문장용으로 만들어져 짧은 hilight 조각에서는 대부분 걸러진다. 2단계 KPF-BERT 관계 판별기로 바꾸는 근거가 된다.

### 3.3 기업쌍 hilight가 캐시되지 않았다 (수정함)

- 검색 종료일이 내일로 잡혀 캐시 규칙(종료일이 오늘 이하)에 걸리지 않았다. 재실행하면 300회를 다시 호출했을 것이다.
- `analyze`의 근거 검색 종료일을 오늘로 바꿨다. 다음 실행부터 캐시된다.

### 3.4 그래프가 전체 기간 정보로 만들어진다 (평가 시 주의)

- 동시언급 NPMI, 최근 20건 근거, COSMOS 관계(2026-09 기준)를 모두 전체 기간에서 만들어 2025년 이벤트에도 적용한다.
- 데모에는 문제없지만, 2단계 시계열 검증이나 발표의 적중률 수치에 그대로 쓰면 미래 정보가 섞인다. 평가용으로는 시점별 그래프를 따로 만들어야 한다.

## 5. 추정 전이 조정 (2026-10-16)

목표: 기사 1건당 추정 OK 3~6개, 근거가 강한 것만 (기획서 [그림 1]과 같은 규모).

실제 이벤트 4,000건 표본으로 먼저 시뮬레이션했다. 기준값을 올리거나 개수만 자르면 같은 회사가 절반 넘는 이벤트에 계속 나왔다. 원인이 허브 구조(삼성전자 관계 41개, SK하이닉스 29개)이기 때문이다. 키워드 조건만 걸면 0개 아니면 15개로 갈렸다. 그래서 네 가지를 함께 적용했다.

| 규칙 | 내용 |
|---|---|
| 출발점 | 제목·본문에 나온 기업(salience 0.8 이상)만 전파한다. 개체명 목록에만 있는 기업은 언급 기업으로 남지만 퍼뜨리지 않는다 |
| 허브 감쇠 | 관계가 8개를 넘는 기업에서 퍼질 때 √(8/관계 수)를 곱한다 (삼성전자 약 0.44) |
| 키워드 활성화 | 기사(제목 + 본문 200자 + 전체 명사)에 해당 단어가 있을 때만 그 관계 종류로 퍼진다. 공급·협력·경쟁은 COSMOS 관계 규칙 키워드, 지분은 별도 키워드를 쓴다. 2단계 KPF-BERT 이벤트 분류기로 바꿀 자리다 |
| 기준·상한 | OK 기준 0.30 → 0.25, OK는 상위 6개, 7등 이하는 "우선순위 밖"으로 보류, 추정은 최대 12개 |

결과 (전체 129,864건 재분석·재적재):

| 항목 | 조정 전 | 조정 후 |
|---|---:|---:|
| INFERRED / OK | 1,936,287 | 281,978 |
| INFERRED / HOLD | 516,465 | 325,342 (전이 강도 낮음 147,865, 우선순위 밖 152,912, 동시언급만 24,565) |
| 제목·본문 언급 이벤트(87,754건)의 평균 추정 OK | 약 15 | 3.21 |
| 그중 3~6개 구간 | 거의 0% | 54.3% |
| 그중 0개 | 3% 안팎 | 38.0% |
| 가장 자주 추정되는 기업의 이벤트 비율 | 95% (Arm) | 30% (한미반도체) |

개체명 목록에만 기업이 있는 이벤트 42,110건은 설계대로 추정 기업이 없다.

남은 한계:

- 추정 기업이 0개인 이벤트(제목·본문 언급 이벤트의 38%)는 기사에 공급·협력·경쟁 같은 단서가 없는 경우다. "근거가 약하면 결과를 내지 않는다"는 기획서 원칙과 맞다.
- 기사의 주인공이 그래프에 관계가 없는 중소형사이면, 추정 기업은 함께 언급된 대기업 쪽 이웃으로 채워진다. 예: "넥스틴, SK하이닉스서 수주" 기사에서 추정 5개가 모두 SK하이닉스의 공급 관계에서 나왔다. 중소형사의 관계를 늘리는 것(근거 관계 수율 개선, DART 지분 관계)이 다음 과제다.
- 근거 조각 수가 실행마다 흔들린다 (51 → 38). 기업쌍마다 최근 20건만 보기 때문에 분석 기간이 하루만 바뀌어도 대상 기사가 달라진다. 기업쌍당 기사 수를 늘리거나 KPF-BERT 판별기로 바꾸면 안정된다.

| 단계 | 결과 | 시간 |
|---|---|---|
| 설치 | torch 2.14.1(CPU), transformers 5.16.1, KR-FinBERT 가중치(리비전 `f8586286…`) | 몇 분 |

시험 구간(2026-07 이후) 비교:

| 방법 | 정확도 | macro-F1 | log-loss |
|---|---:|---:|---:|
| 항상 중립 | 0.487 | 0.218 | - |
| 규칙(감성 × 경로 부호) | 0.421 | 0.381 | - |
| 감성만 | 0.492 | 0.295 | 1.062 |
| 전체 모델 | 0.492 | 0.345 | 1.054 |

- 모델은 "항상 중립"보다 정확도가 0.5%p 높을 뿐이고, macro-F1은 규칙 기준선보다 낮다. τ 기준을 통과하지 못해 기본값 0.6을 썼고, 시험 구간에서 신뢰도가 0.6을 넘는 예측이 없어 커버리지는 0%다. 지도에는 국내 상장사가 모두 속 빈 원(방향 보류)으로 나온다.
- 원인 1. 신호가 약하다. 가장 중요한 입력(부정 감성)을 섞어도 log-loss가 0.008 늘 뿐이다. 기사 다음 날 일별 주가는 이 입력들로 거의 설명되지 않는다.
- 원인 2. 구간마다 시장 분위기가 다르다. 중립 비율이 검증 38%, 시험 49%다. 검증 구간에 맞춘 확률 보정이 시험 구간에서 어긋나 신뢰도가 0.5 아래에 머문다(보정표: 평균 신뢰도 0.38 구간의 실제 정확도 0.46).
- 규칙 기준선의 macro-F1이 더 높다는 것은 감성 × 관계 부호에 방향 정보가 조금은 있다는 뜻이다. 모델은 log-loss를 줄이도록 학습돼 대부분 중립으로 답한다.
