# 기업 탭 주식 화면 — 설계 (2026-10-26)

기업 탭(`/companies`)을 관계 중심 목록에서 주식 시세판으로 바꾸고, 기업 상세 페이지(`/companies/:id`)를 새로 만든다.
관계 정보는 남기되 주가·지표가 먼저 보이게 한다. 11-03 발표에서 심사위원이 기업 탭을 열었을 때 투자 정보 화면으로
읽히는 것이 목표다. 마감(10-30) 안에 끝낼 크기로 자른다.

## 정한 것

| 항목 | 값 |
|---|---|
| 상세 위치 | 새 페이지 `/companies/:id` (사용자 선택). 목록 행을 누르면 이동한다 |
| 데이터 방식 | 백엔드에 시세 API 3개를 더한다. 계산은 SQL, 61종목이라 목록은 페이지 없이 한 번에 받는다 |
| 범위 | 주가가 있는 반도체 61종목(코스피·코스닥). 주가가 없는 기업은 목록에 남기고 시세 칸만 '-' |
| 주가 기준 | `stock_price_history` 일봉(1D)의 마지막 거래일. 지금은 2026-10-23 |
| 등락 기간 | 거래일 수로 센다: 1일 = 1거래일 전 종가 대비, 1개월 = 20거래일, 3개월 = 60거래일 |
| 관계 기준 | 공개 은하 스냅샷의 1년(1Y) 관계. 목록의 연결 관계 수와 상세의 관계 기업 목록이 같은 기준이다 |
| 원칙 | 관측된 숫자만 보여 준다. 오른다·내린다를 말하거나 매수·매도를 권하지 않는다 |
| 빼는 것 | 캔들 차트, 실시간 시세, 이동평균 같은 기술적 지표, 거래량 차트 |

## 참고한 서비스 (2026-10-26 직접 확인)

| 서비스 | 화면 | 가져올 것 |
|---|---|---|
| 토스증권 주식 골라보기 (`tossinvest.com/screener`) | 목록 | 왼쪽 골라보기 묶음(연속 상승세·저평가·배당주), 위 필터 칩(시장·산업·시가총액·등락률), 순위 표(현재가·등락액·등락률·업종·시가총액·관심 하트) |
| 토스증권 종목 화면 (`tossinvest.com/stocks/A000660`) | 상세 | 머리 줄(가격·등락 + 1일 범위·52주 범위 막대, 시가총액 순위), 투자 지표 묶음(가치평가 PER·PBR / 수익 EPS·BPS·ROE / 배당), '다른 종목과 비교하기'(같은 업종 순위 표 + 업종 중앙값 줄 + 한 줄 해석), 하단 지수 띠 |
| Google Finance 종목 화면 (`google.com/finance/quote/000660:KRX`) | 상세 | 기간 탭과 '비교'(지수 겹쳐 보기) 차트, 핵심 수치 격자(시가·고가·저가·거래량·52주 최고·최저·시가총액), 오른쪽 '관련 주식'(이름·가격·등락) 과 뉴스 목록 |
| 네이버 증권 | — | 이 브라우저에서 열 수 없게 막혀 있어 보지 못했다 |

색은 국내 서비스(토스·네이버·Google 한국어) 관례대로 **오르면 빨강, 내리면 파랑**으로 한다. 이 두 화면의 가격 등락에만 새 색
토큰(`--rise`, `--fall`)을 쓰고, 다른 화면의 `--pos`·`--neg`(감성·과거 경향)는 건드리지 않는다.

## 1. 기업 목록 `/companies` — 시세판 (토스 골라보기 + Google 시장 요약)

- **시장 띠** (맨 위, 가로 카드)
  - 코스피·코스닥: 지수, 전일 대비(포인트·%), 최근 3개월(60거래일) 미니 차트
  - 반도체 종목 등락 분포: "상승 n · 보합 m · 하락 k" 막대 하나
  - 오른쪽 끝에 "주가 2026-10-23 종가 기준"
- **골라보기 칩** (토스의 왼쪽 묶음을 칩 한 줄로): 전체 · 시가총액 상위 · 1개월 상승 · 1개월 하락 · 낮은 PER(흑자만) · 배당주
  (배당수익률 순) · 관계 많은 기업. 칩은 정렬·필터 조합을 바꾸는 단축키다
- **필터**: 검색(이름·코드), 시장(코스피·코스닥), 산업, 규모(대형·중형·소형). 지금 들어 있는 나스닥 선택지는 뺀다
- **표**: 순위 | 관심(별) | 기업(로고·이름·코드·산업 칩) | 현재가 | 등락(등락액·등락률) | 1개월 추이(미니 차트, 21개 종가) |
  1개월 | 시가총액(규모 배지) | PER | PBR | 배당 | 관계(연결 수)
  - 숫자 열은 오른쪽 정렬·고정폭 숫자. 머리를 누르면 그 열로 정렬(다시 누르면 반대). 기본은 시가총액 내림차순
  - 적자 기업(순이익 < 0)은 PER 칸에 '적자'. 값이 없으면 '-'
  - 행 전체가 링크다: 누르면 `/companies/:id`. 마우스를 올리면 행 강조
- '투자·지분 관계' 보기 전환은 그대로 둔다
- 좁은 화면: 기업·현재가·등락·1개월 추이만 남기고 나머지 열은 숨긴다

목록은 시세 API 하나로 그린다. `/companies` 무한 스크롤과 프론트의 예비 시가총액 표(`lib/marketCapFallback.ts`)로 정렬하던
방식은 쓰지 않는다(예비 표는 다른 곳에서 쓰지 않으면 지운다).

## 2. 기업 상세 `/companies/:id` (토스 종목 화면 + Google Finance)

**머리 줄** (토스): 로고, 이름, 코드·시장·업종 칩, 큰 가격, 등락(등락액·등락률, 빨강/파랑), "10월 23일 종가". 오른쪽에
1일 범위 막대(저가—고가 사이 종가 위치), 52주 범위 막대, 시가총액·순위, 거래대금. 버튼: 관심(별), '관계 은하에서 보기'.

본문은 넓은 화면에서 두 칸이다. 왼쪽이 넓다.

**왼쪽**
- **차트** (Google): 기간 탭 1M · 3M · 6M · 1Y(기본 3M). '지수와 비교' 켜기·끄기(기본 켬)
  - 켬: 종목과 소속 시장 지수(코스피 종목은 코스피, 코스닥 종목은 코스닥)의 기간 누적 수익률 두 선
  - 끔: 종가 선과 영역, 기간 첫날 종가 점선
  - 마우스를 올리면 세로선과 그날 날짜·종가·종목 수익률·지수 수익률
  - 차트 아래 한 줄: "3개월 +12.3% · 코스피 +4.1% · 차이 +8.2%p"
- **핵심 수치 격자** (Google): 시가, 고가, 저가(마지막 거래일), 거래량, 거래대금, 52주 최고·최저, 시가총액(순위)
- **투자 지표** (토스, 세 묶음)
  - 가치평가: PER, PBR — 각각 옆에 같은 업종 중앙값
  - 수익: 순이익(최근 4분기), EPS, BPS, ROE
  - 배당: 주당 배당금, 배당수익률
  - EPS·BPS 는 상장주식수(시가총액 ÷ 종가)로 나눠 계산하고, ROE 는 순이익 ÷ 자본총계. "계산값"이라고 작게 적는다
  - 기준: 재무 기준(`fiscal_basis`)·주가 날짜
- **같은 업종 비교** (토스 '다른 종목과 비교하기'): 같은 대표 업종 기업을 시가총액 순으로 순위·이름·PER·시가총액·주가·1개월.
  이 기업 줄은 강조하고, 업종 중앙값 줄을 끼운다. 위에 한 줄: "반도체 장비 업종 중앙값보다 PER이 낮아요(5.6배 · 중앙값
  15.2배)". 비싸다·싸다·사라·팔라는 말은 하지 않는다

**오른쪽**
- **관계 기업 동향** (Google '관련 주식' 자리, NEXUS의 차별점)
  - 요약 칩: "관계 기업 n곳 · 1개월 상승 a · 하락 b · 평균 ±x%"
  - 관계 점수 순 목록: 로고·이름, 관계 종류 칩, 현재가, 1일 등락, 1개월 미니 차트, 1개월 등락. 누르면 그 기업 상세
  - 관계 종류는 방향을 풀어 쓴다: 공급(상대가 나에게 공급 → '공급사', 내가 상대에게 → '고객사'), 투자(상대가 나에게 →
    '지분 보유사', 내가 상대에게 → '지분 투자처'), 협력 → '협력사', 경쟁 → '경쟁사', 함께 언급 → '함께 언급'
  - 같은 상대와 관계가 여러 개면 점수가 가장 높은 하나만 보여 주고 나머지 종류는 작은 글씨로 덧붙인다
- **최근 뉴스** (Google 뉴스 목록): 이 기업이 나온 뉴스 이벤트(`GET /events/company-history`)를 날짜·언론사·제목으로.
  누르면 그 뉴스의 이벤트 화면(`/?event=`)

좁은 화면에서는 한 칸으로 쌓는다: 머리 → 차트 → 관계 기업 동향 → 투자 지표 → 업종 비교 → 뉴스.

## 3. 백엔드 API (새로 3개)

모두 공개 GET. `SecurityConfig.PUBLIC_GET_PATHS` 에 `/api/market/**` 를 더한다(`/api/companies/**` 는 이미 공개).

### `GET /api/market/indices?period=3M`

- period: 1M · 3M · 6M · 1Y (거래일 20 · 60 · 120 · 250개, 기준점 하나를 더 준다)
- 응답: `{ asOf, items: [{ indexCode, close, change1d, change1m, points: [{ date, close }] }] }` — KOSPI, KOSDAQ 순
- 출처: `market_index_price`

### `GET /api/companies/quotes`

- 페이지 없이 활성 기업 전부. 응답 `{ asOf, items: [CompanyQuote] }`
- `CompanyQuote`: companyId, name, stockCode, market, industry(대표 업종), close, prevClose, tradingDate, change1d,
  change1m, change3m, spark(최근 21개 종가, 오래된 것부터), marketCap, marketCapRank, sizeClass, per, pbr, dividendYield,
  dividendPerShare, netIncomeTtm, equity, fiscalBasis, priceDate, relationCount(1Y)
- 주가가 없으면 시세 칸이 null, 재무가 없으면 재무 칸이 null
- 출처: `company`, `stock_price_history`(창 함수로 마지막 61개 종가), `company_fundamental`, `relationship_score_current`
  (공개 스냅샷, 1Y)

### `GET /api/companies/{id}/related`

- 응답 `{ companyId, window: "1Y", items: [{ relationType, direction, score, otherTypes[], quote: CompanyQuote }] }`
- direction: OUT(이 기업이 source) · IN(이 기업이 target) · NONE(방향 없는 관계)
- 점수 내림차순. 같은 상대는 최고 점수 하나로 묶는다(1번 절 규칙)
- 없는 기업 id는 404

상세 화면은 기존 `GET /api/companies/{id}/stock-prices?period=1Y` 와 `GET /api/market/indices?period=1Y` 를 한 번씩 받아
기간 탭(1M~1Y)은 프론트에서 잘라 쓴다. 1일 범위·핵심 수치·52주 범위도 이 일봉에서 계산한다.

## 5. 오류·빈 값

- 주가가 없는 기업: 시세 칸 '-', 상세 차트 자리에 "주가 데이터가 없습니다"
- 재무 일부만 있음: 있는 칸만 채운다(`docs/api-specification.md` 의 fundamental 설명과 같다)
- 관계 기업이 없음: "공개 은하 스냅샷에 이 기업의 1년 관계가 없습니다"
- 지수 API 실패: 시장 띠만 숨기고 표는 그린다

## 8. 구현하며 달라진 점 (2026-10-26)

- 숫자 표기는 이벤트 화면과 같은 함수를 쓴다: 등락률의 음수 부호는 '−', 시가총액은 100조 이상이면 정수(예: 933조).
- 시세판은 주가가 있는 종목만 보여 준다. 주가가 없는 12곳은 모두 나스닥 기업이라(2026-10-18 국내 종목만으로 정함) '-'만 있는 줄이 된다. API 는 그대로 돌려준다.
- 휴대폰 폭(600px 이하)에서는 1개월 추이(미니 차트) 열도 숨긴다. 넣으면 표가 카드보다 100px 넓어진다. 골라보기 칩은 한 줄로 두고 옆으로 민다.
- 미리보기 창(`CompanyPreviewDialog`)은 쓰는 곳이 없어져 지웠다. 그 안의 뉴스 이력은 `CompanyNewsHistory` 로 떼어 상세 페이지 '최근 뉴스'에 쓴다(지표 칸은 상세 페이지와 겹쳐 뺐다).
- 관계 기업 동향은 처음에 8곳만 보여 주고 '모두 보기'로 편다(SK하이닉스는 22곳이라 오른쪽 열이 너무 길어졌다).
- 상세 머리 줄의 거래대금은 마지막 거래일 종가 × 거래량이다(거래대금 원자료가 없다). 화면에 그렇게 적는다.
- 다른 화면에서 들어오는 길: 이벤트 카드의 '종목 상세 · 뉴스 이력' 버튼, 관계 은하 기업 패널의 '종목 상세' 칩. 예전 주소 `/companies?company=` 는 상세로 넘긴다.
- 같은 업종 비교는 시가총액 순이 아니라 PER 낮은 순(적자·값 없음은 뒤)으로 놓는다. 업종 중앙값 줄을 끼우는 자리가 PER 순서에서만 뜻이 있어서다.
- 최종 검토(10-26)로 고친 것: 종목을 옮길 때 이전 종목의 일봉이 잠깐 보이던 것(불러오는 중으로 둔다), 지수가 늦거나 실패하면 차트가 "데이터 부족"이라고 하던 것(불러오는 동안은 대기, 실패하면 주가 모드로 그리고 안내), 적자 금액의 부호·단위(−2.0조), 0.5% 눈금이 "1%"로 찍히던 것, 별 버튼의 Enter 가 행 이동까지 일으키던 것.
